# Dormly – Student Accommodation Platform

**Find Your Stay. Feel at Home.**

Dormly is a student-focused accommodation platform designed to help university students and working professionals discover safe, affordable, and verified hostels. It simplifies hostel hunting through location-based discovery, transparent pricing, room availability, booking requests, and trust-focused safety features.

## 🎯 Project Overview

Finding suitable accommodation can be challenging due to fake listings, misleading photos, hidden charges, and safety concerns. Dormly aims to make this process easier, safer, and more transparent.

## ✨ Key Features

### Student / Seeker
- Search hostels by city, area, and location.
- Filter by budget, gender, facilities, and room type.
- View hostel details, photos, prices, and availability.
- Compare hostels and save favorites.
- Send booking requests and schedule visits.
- Chat with hostel owners.
- Submit reviews after a confirmed stay.
- Report suspicious or unsafe listings.

### Owner / Manager
- Create and manage hostel listings.
- Upload property photos and verification documents.
- Manage rooms, beds, pricing, and facilities.
- Accept or reject booking requests.
- Schedule visits and manage residents.
- Track hostel performance and reviews.

### Resident
- View active stays and rent history.
- Record payments.
- Submit maintenance complaints.
- Request checkout and leave reviews.

### Admin
- Verify owners and properties.
- Approve or reject hostel listings.
- Review reports and moderate content.
- Manage users and enforce platform policies.

## 🛡️ Trust & Safety
- Verified Owner and Verified Photos badges.
- Property verification and admin approval.
- Women-only hostel identification.
- Privacy-protected contact information.
- Visit-first booking approach.
- Reviews restricted to confirmed residents.
- Reporting, blocking, and listing moderation.

## 🛠️ Technology Stack

- **Frontend:** Flutter & Dart
- **Backend:** Firebase
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Storage:** Firebase Storage
- **Notifications:** Firebase Cloud Messaging
- **Server Logic:** Firebase Cloud Functions
- **Maps:** Google Maps API

## 👥 User Roles
1. Seeker
2. Owner / Manager
3. Resident
4. Administrator

## 🔐 Security & Privacy

Dormly prioritizes user privacy, role-based access, secure authentication, and verified accommodation listings. Sensitive documents and contact details must be protected through appropriate Firebase security rules.

## ⚠️ Disclaimer

Dormly facilitates hostel discovery but does not guarantee the actual condition or safety of any property. Users should visit and verify accommodation before making financial commitments. Payments are handled outside the platform in the initial version.
